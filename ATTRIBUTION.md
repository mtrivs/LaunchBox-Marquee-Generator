# Attribution

The shared composition and visual effects were adapted from existing Community Theme Creator marquee templates. Original template names are retained in the `template_source` fields of `profiles.json`.

The renderer uses bundled template components and platform artwork in `assets/`, together with media from the user's own LaunchBox installation. Scraped game libraries, generated sample collections and ROMs are not included in this repository.

Pillow is installed separately as a dependency: https://github.com/python-pillow/Pillow.

LaunchBox, Big Box, Community Theme Creator, console names and logos identify the software/platforms supported by this independent utility.
